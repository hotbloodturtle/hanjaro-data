# hanjaro-data

한자 학습 앱 **한자로**(Android, `com.ingbale.hanjaro`)가 쓰는 가공 자료입니다.

| 파일 | 내용 | 출처 | 라이선스 |
|---|---|---|---|
| `words.json` | 한자별 대표 한자어·뜻풀이, 사자성어(뜻·예문), 동음이의어 묶음 | 국립국어원 「한국어기초사전」(https://krdict.korean.go.kr) 자료를 발췌·수정 | [CC BY-SA 2.0 KR](https://creativecommons.org/licenses/by-sa/2.0/kr/) |
| `strokes.json` | 8~5급 한자 획 모양·획 중심선(쓰기 연습용, y 좌표 뒤집음) | [AnimCJK](https://github.com/parsimonhi/animCJK)(한국 필순) · [Hanzi Writer Data](https://github.com/chanind/hanzi-writer-data)(Make Me a Hanzi) — Arphic PL KaitiM 글꼴 유래 | Arphic Public License (`licenses/`) |

- `words.json` 은 원자료와 같은 조건(CC BY-SA 2.0 KR)으로 누구나 이용·수정·배포할 수 있습니다. 이용할 때는 출처(국립국어원 한국어기초사전, 한자로 가공)를 밝혀 주세요.
- `strokes.json` 은 Arphic Public License 를 따릅니다. 원 자료의 저작권 표시는 `licenses/` 에 있습니다.
- 앱 글꼴 Jua 의 라이선스(SIL OFL 1.1)도 `licenses/` 에 함께 둡니다(이 레포의 자료는 아님).
